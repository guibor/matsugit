# Folioforge

Read README.org before editing. Keep this package independent of any editor,
account, organization, theme, or private publishing configuration.

Use synthetic fixtures and local Git remotes in tests. Never publish real
documents, enable public hosting, alter credentials, or overwrite unrelated
work. Run `python3 -m unittest discover -s tests` before committing.

Document code is data: never execute it. Themes are explicitly selected,
trusted inputs. Copy only manifest-listed theme files and referenced assets.
