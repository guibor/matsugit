## One intake, clear accountability

:::: {.implication relation="enables"}
#### What changes
- One entry point for requests.
- A named owner for each handoff.
- A shared review of unresolved work.

#### What it enables
- Teams know where to take a request.
- Delays have an accountable owner.
::::

## Match each insight to an action

::: {.mapping relation="suggests"}
| Insight | Action |
| :--- | :--- |
| Ownership changes during handoff. | Name one accountable owner. |
| Requests arrive through several channels. | Test a shared intake. |
| Faster delivery can conceal rework. | Pair the speed target with a quality gate. |
| Results use different measurement windows. | Compare the same period. |
:::
