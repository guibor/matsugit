# matsugit

Your deck is a document. Write it like one.

![Edit the words and shape the story](docs/images/workspace/visual-story-demo.gif)

Turn notes into slides, edit the wording directly, and arrange the argument in
Story. One Markdown file stays behind the slides and reading document. Runs
locally with Cursor, Codex, Claude or an ordinary browser. Sharing is optional
and uses your own Git repository; opening a deck publishes nothing.

**[Screenshots, installation and the full guide](README.org)**

Claude Code: `/plugin marketplace add guibor/matsugit`, then
`/plugin install matsugit@matsugit`. Try `/matsugit:matsugit-tour`.
See the [Claude guide](docs/claude.md) for Desktop setup and prerequisites:
Node 22+, Python 3.10+, Git, Quarto and a compatible Pandoc converter.
