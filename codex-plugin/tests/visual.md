# Decision

## Start with a focused pilot
### Prove the experience before expanding

Review **the evidence**, *the tradeoffs*, and [the report](https://example.com/a-long-report-address).

- One accountable owner.
- A measurable review gate.

| Measure | Baseline | Pilot target |
| :--- | ---: | ---: |
| Cycle time | 12 days | 8 days |
| Rework | 18% | At most 18% |

::: takeaway
Expand only when speed improves without increasing rework.
:::
