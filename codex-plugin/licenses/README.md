# Dependency notice supplements

`@cfworker/json-schema` 4.1.4 declares MIT but omits its license file from
the npm tarball. `cfworker-json-schema-4.1.4.txt` is the unmodified license at
the package's npm `gitHead`:

https://github.com/cfworker/cfworker/blob/e45acacf25e083ac1b4b09bdd940d27c33bffcc5/LICENSE.md

The supplement is version-specific. On upgrade, check the new package and
its published revision rather than silently reusing an old notice.
