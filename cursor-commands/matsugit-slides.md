# Open the slide workspace

Follow the matsugit skill and call `matsugit_open` for the explicitly selected
Markdown/Org file with `layout: split` and `format: slides`. Preserve the
configured project/host theme. The screen icon enters Present mode; Escape
returns to editing. Do not publish or rewrite the source just to open it.

If the matsugit tools are missing or nothing appears, run `python3 -m matsugit open
<absolute path>` from the matsugit checkout and give the address it prints.
