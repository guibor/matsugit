# Rename compatibility

The product is now **matsugit**, always lowercase; GitHub: `guibor/matsugit`.
The CLI, Python package and skill are `matsugit`; Codex uses `matsugit@matsugit`.
Read the full migration guide in the checkout's `docs/migration.org`, or at
https://github.com/guibor/matsugit/blob/main/docs/migration.org.

Existing `folioforge.json`, global settings, `FOLIOFORGE_*` environment variables,
Python imports and CLI commands remain supported. Do not rename an active
working directory, erase recovery records or modify archived release bundles.
Keep theme choices, publication URLs, permissions and CI approval rules intact.

Save/download drafts before closing old viewers. Install the new plugin before
removing the old one; start a new agent session to discover the renamed tools.
No document publication is needed to test this migration. Use synthetic data.
